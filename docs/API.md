# REST API reference (wv-members/v1)

Base: `/wp-json/wv-members/v1`. Every response is `{ data, meta?, error? }`; lists accept `?page=&per_page=` and return `meta.total`, `meta.pages`. Errors: `{ data: null, error: { code, message, fields } }` with HTTP 4xx/5xx. Cookie auth with `X-WP-Nonce` (or `_wpnonce` query param for downloads).

Permissions: `/public/*` unauthenticated; `/me/*` logged-in member (self only); everything else needs the capability noted in the controller (see §3 of the brief / docs/ADMIN_MANUAL.md).
